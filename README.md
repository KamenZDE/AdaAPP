# Co je za den

Moje první webová aplikace. Tlačítko, které po kliknutí vypíše aktuální den v týdnu česky.

## Jak to spustit

Otevři `index.html` v prohlížeči. Nic se neinstaluje.

## Z čeho se to skládá

Celá appka je v jednom souboru `index.html`:

- **HTML** (`<button>`, `<div>`) — obsah stránky
- **CSS** (`<style>`) — vzhled
- **JavaScript** (`<script>`) — chování po kliknutí
